# MediHire

Sample healthcare job board and hospital directory. The interface is a React, Vite, and TypeScript app with local mock data. There is no backend, no accounts, and no collection of personal information.

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Routes

- `/` Home
- `/jobs` Job board
- `/jobs/:slug` Job details
- `/hospitals` Hospitals directory
- `/hospitals/:slug` Hospital details

Design tokens live in `src/index.css`. Sample hospitals and roles live in `src/data`.
